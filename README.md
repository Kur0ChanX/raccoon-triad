# Raccoon Triad

Gioco di carte in stile Triple Triad: 320 carte di personaggi di videogiochi famosi, buste, foil (Holo, Reverse, Full Art, Oro, Segreta), visore 3D con doppio tocco, Arena, Torre infinita, sfida del giorno, sfide online con gli amici e stagioni mensili.

**Gioca:** https://kur0chanx.github.io/raccoon-triad/

Per sviluppare vedi `CLAUDE.md`. Per il server online vedi `tools/triad-server/README.md`.
